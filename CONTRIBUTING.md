# Contributing to DomainBlocks

Thanks for your interest in contributing!

## Before you start

All contributors must sign a Contributor License Agreement (CLA) before their contributions can be accepted. See the
[DomainBlocks CLA repository](https://github.com/DomainBlocks/cla) for details.

## Building and testing

```shell
dotnet build
dotnet test          # unit and integration tests; the integration tests need Docker
```

See [tests/README.md](tests/README.md) for how the tests are organised and [benchmarks/README.md](benchmarks/README.md)
for the benchmarks, which a plain `dotnet test` does not run.
